# Per-Decision Ablation (Rebuttal E3 — tWK8 W2/Q2)

Isolates the contribution of each of ARC's four decision types
(**workflow / tools / budget / prompt**). Two mechanisms are provided.

## 1. Eval-time freeze (cheap; already run on GSM8K)

`scripts/eval_hrl_ablation.py` wraps `eval_hrl.py` and freezes one structure-action
dimension of a TRAINED policy at eval time (accepts all eval_hrl flags):

```bash
python scripts/eval_hrl_ablation.py --structure-model <sft.pt> --prompt-model <sft.pt> \
  --dataset gsm8k --api --api-model qwen/qwen-2.5-7b-instruct --episodes all --workers 8 \
  --freeze-workflow 2        # or: --freeze-tools 3 | --freeze-budget 1 | --freeze-prompt
```

Structure action layout: [0]=workflow(9), [1]=agent1_tools(16), [2]=agent1_budget(3),
[3]=agent2_tools(16), [4]=agent2_budget(3), [5]=answerer_budget(3).
`--freeze-tools K` sets dims 1&3; `--freeze-budget K` sets dims 2,4,5;
`--freeze-prompt` makes the prompt policy emit DONE (no learned atoms).

Results (GSM8K n=1319, fresh PPO-20k + SFT policy, full=87.3%):
freeze tools(3) 85.5 (−1.8) | budget(1) 86.4 (−0.9) | workflow(2) 87.1 (−0.2) |
prompt 88.1 (+0.8, within ±0.9 binomial noise).

## 2. Train-time leave-one-out (causal; implemented, NOT yet run — needs API budget sign-off)

Removes a dimension from the action space DURING training via the masked-PPO
machinery (no gradient hacks). Env-var gated, default no-op:

```bash
# structure dims: constrain to one legal value (JSON)
ARC_TRAIN_FREEZE='{"tools": 3}'   python train.py --algorithm ppo --mask --api ...
ARC_TRAIN_FREEZE='{"workflow": 2}' ...
ARC_TRAIN_FREEZE='{"budget": 1}'   ...
# prompt dimension: force DONE on every slot
ARC_FREEZE_PROMPT=1 python train.py --algorithm ppo --mask --api ...
```

Requires `--mask`. Hooks live in `env/structure_env.py` (`_get_action_mask`) and
`env/prompt_env.py` (`step`). After training run SFT + eval as usual.

Recommended protocol (defensible against "bad default" critiques):
1. Choose each dimension's static default by an eval-time freeze sweep on the
   VALIDATION split (pick the best-performing frozen value).
2. Retrain with that dimension masked to the chosen default (commands above).
3. Report full-vs-ablated on the full test split, 2–3 datasets
   (suggested: gsm8k, hotpotqa; medqa prompt-dim already covered by the
   library experiment below).
4. Optional strongest evidence, no retraining: per-query counterfactual sweep —
   for ~150 test queries, re-execute with each alternative value of one dimension
   and report (a) % of queries where the choice flips correctness and (b) how
   often the policy picks the winning value.

## Enriched self-generated prompt libraries (tWK8 W3)

`prompts/generated_v2/{gsm8k,medqa}_qwen_enriched/atoms.json` are ENLARGED atom
sets (15/10/10 vs default 10/7/7) generated by the qwen-2.5-7b BACKBONE itself
(no frontier model; repo default generator was claude-opus-4.7).
`prompts/generated_v2/medqa/atoms.json` on this branch IS the enriched set
(originals kept as `atoms.json.frontier_orig`); gsm8k's active file is the original.

Result: MedQA 58.4 → **69.2** (n=1273, PPO-20k + SFT, only the library changed).
Generation caveat: greedy decoding collapses to one repeated instruction —
generate with temperature ~0.95, exact-text dedup, and rotating topical anchors.
